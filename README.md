# yomikoe-models

[Yomikoe](https://github.com/tearforfear007/yomikoe)（日文口說學習 app）
「日本の友達ヒカリ」對話功能用的本地 LLM 模型檔（MediaPipe/LiteRT `.task` 格式）。

模型放在 [Releases](../../releases)。手機瀏覽器登入 GitHub 下載後，
在 app 的聊天室 → ⋮ → 「匯入 .task 檔」即可使用。
